关于凌曦安全团队

凌曦安全团队(LingXisec)成立于 2023 年，团队成员来自头部安全厂商、科技企业、高校与独立安全研究社区，深耕漏洞挖掘、红蓝对抗、云安全、JS 逆向、终端防御与代码审计领域；团队持续向各大厂商 SRC 提交高质量漏洞，斩获多项 SRC 平台荣誉，同时面向网安新人开设实战向安全培训，包含 SRC 漏洞研究、红蓝对抗系列课程，采用录播 + 直播 + 社群答疑模式，配套内部靶场、简历与模拟面试辅导，B 站也开放免费入门教学资源，团队坚持技术开源分享，持续输出漏洞复现、实战 WriteUp 等技术文章，在 GitHub 开放安全靶场与自研安全工具，致力于搭建开放的网络安全交流成长社区，欢迎广大安全从业者与爱好者交流探讨。
